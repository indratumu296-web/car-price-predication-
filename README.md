# 🚗 Car Price Prediction using Machine Learning

## 📌 Project Overview
This project predicts the selling price of a car using a Machine Learning Linear Regression model. The application is built with Python and deployed as a web application using Flask.

This project was developed as part of the **FLAME'26 Hands-on Workshop**.

---

## 🚀 Features

- Predicts car selling price
- User-friendly web interface
- Machine Learning Linear Regression model
- Fast and accurate predictions
- Ready for deployment on Render

---

## 🛠️ Technologies Used

- Python
- Flask
- Scikit-learn
- NumPy
- Pandas
- HTML/CSS

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/your-username/car-price-prediction.git
```

Go to the project folder:

```bash
cd car-price-prediction
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
python app.py
```

---

## 🌐 Deployment

This application is deployed on **Render**.

## 📊 Machine Learning Model

- Algorithm: Linear Regression
- Input: Car details
- Output: Predicted Car Price
